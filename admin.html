⚙️ SETTING BACKUP DRIVE (ADMIN)
Client ID Google (dari Google Cloud Console) Client Secret (wajib untuk tipe Web application)
Auto backup ke Drive tgl 15 & 30
📖 Cara buat Client ID (sekali saja)
1. Buka console.cloud.google.com → buat Project baru.
2. Menu APIs & Services → Library → cari & aktifkan Google Drive API.
3. OAuth consent screen → pilih External → tambahkan email kamu sebagai Test user.
4. Credentials → Create credentials → OAuth client ID → pilih tipe Web application.
5. Di Authorized redirect URIs, tambahkan URL halaman admin ini (lihat di bawah), lalu Save.
6. Salin Client ID dan Client Secret (klik ✏️ pada client → panel kanan muncul keduanya) ke kolom di atas → Simpan → Hubungkan.
7. Penting: untuk tipe Web application, Google mewajibkan Client Secret saat tukar kode — tanpa itu muncul error client_secret is missing.
